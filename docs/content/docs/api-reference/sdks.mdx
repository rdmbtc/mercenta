---
title: "SDK integration"
description: "Use the HTTP API from your trusted server."
---

The current public account API is HTTP/JSON. There is no published Mercenta client SDK guarantee. Keep API keys server-side and use your standard HTTP client with timeouts.

Circle App Kit and the Viem adapter are server integration dependencies, not a license to sign autonomously. Human wallet signatures are required for blockchain execution. No model receives a wallet private key.

Internal supply integrations are represented only as Wholesale Provider or Fulfillment Gateway. Their proprietary details and credentials are not public API contracts.
