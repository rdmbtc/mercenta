---
title: "Unified balance"
description: "Wallet, Gateway and account balances are distinct."
---

A wallet balance is not a Gateway balance, and neither automatically becomes a Mercenta account credit. Track each source separately and reconcile actual destination settlement.

The current customer console shows wallet USDC and verified account available/reserved funds. Gateway funding is not enabled. No cross-network balance or settlement status is invented when the adapter is unavailable.
