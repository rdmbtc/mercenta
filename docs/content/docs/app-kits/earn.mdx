# Earn & Autonomous Treasury Sweeper

Mercenta provides enterprise yield optimization for merchant cashflows and autonomous store operators on **Arc Mainnet (5042)** through the **Autonomous Treasury Sweeper** (RFB 01 Intelligent Business Treasury), alongside testnet vaults for scenario simulation.

---

## 1. Treasury Sweeper Simulation (Scenario Planning)

In digital goods commerce, merchants track operating cashflow separately from reserve buffers. The **Treasury Sweeper** (`/api/treasury/sweep`) models automated allocation of surplus balances using scenario parameters without moving on-chain funds:

* **Chain Reference**: `5042` (Scenario planning mode)
* **Reference Target Vault**: Simulation metadata (`galaxy-usdc` / placeholder `0x32A44B04C8567dB1a613271167E1402CeF5E8c1b`, no live deployed Arc contract at this address)
* **Underlying Asset**: USDC (6 decimals)
* **Simulated Reference Yield**: 8.4% scenario parameter (illustrative only, not verified APR or live payout)
* **Simulation Endpoint**: `POST /api/treasury/sweep`

---

## 2. Operating Reserve Floor Protection

To ensure an automated merchant never runs out of working capital for order fulfillment or customer refunds, the sweeper enforces a **Deterministic Liquidity Floor**:

```
Total Merchant Wallet Balance ($2,450 USDC)
  ├── Operating Liquidity Floor: $500 USDC ──► LOCKED in wallet for instant fulfillment
  └── Surplus Idle Capital:      $1,950 USDC ──► AUTOMATICALLY SWEPT into Morpho Vault (8.4% APY)
```

1. **Configurable Floor**: The store operator or owner agent sets an exact reserve floor (e.g. $250, $500, or $5,000 USDC).
2. **Deterministic Invariant**: A sweep transaction will **never execute** if the post-sweep balance would drop below the configured reserve floor.
3. **Instant Redemption**: Funds deposited into the Morpho Blue vault can be withdrawn on demand whenever operational liquidity requirements increase.

## 3. Sweeper API Specification

Autonomous store agents trigger sweeps programmatically:

```http
POST /api/treasury/sweep
Content-Type: application/json

{
  "walletAddress": "0x9ED914F8C356FE8C3673fB57601A94b3A8B5760",
  "minReserveFloor": 500,
  "continuousMode": true,
  "maxSweepCap": 10000
}
```

## 4. Testnet Discovery & Scenario Simulation

On Arc Testnet (`5042002`), merchants can test APY models and compounding calculators without moving funds under **Account → Finance → Earn**.

* The initial APY assumption defaults to 0%.
* Testnet vault addresses are queried through the installed Circle SDK metadata cache.
* Testnet balances do not generate real yields and cannot be transferred to production vaults.
