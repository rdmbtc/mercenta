---
title: "Circle integration status"
description: "Installed interfaces are not live settlement."
---

Circle App Kit and its Viem adapter are installed and typed. This documents the implementation boundary, not a claim that every Circle product or deployment is available on the chosen test network.

| Module | Current state |
| --- | --- |
| Earn | Read-only testnet SDK metadata and user-assumption calculator; execution disabled |
| Borrow | Sandbox risk calculator; no live signer |
| Onramp | Configuration status; server gate requires credentials and verified route |
| Swap / Bridge | Execution integration boundary; no account funding enabled |
| Gateway | Unified-balance integration boundary; no verified account attribution |

Validate network support, contract addresses, SDK versions and user-signing flows against official Circle documentation before enabling a route. A returned SDK operation is not confirmed settlement.
