---
title: "AI advisor"
description: "Ten consultations without financial authority."
---

The advisor proposes catalog recommendations and treasury explanations. It cannot sign or spend. Ten free consultations are enforced per authenticated wallet or server-created visitor session.

Without valid server-side LLM credentials, the UI labels a rule-based advisor. It does not pretend to be a live model. Provider failures restore quota according to the backend's request handling. On the eleventh request, free access is exhausted. Mainnet paid AI micropayments are not enabled.

Only the neutral label LLM Model Provider is public. Never publish provider credentials or private model-routing details.
