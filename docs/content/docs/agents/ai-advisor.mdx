## Ask before signing in

Open **Assistant → Chat** in [Mercenta](https://app.mercenta.xyz/app?section=agent-chat). Guest help can explain the interface, regions and spending limits without a wallet. It has no private history, balance tools, purchase plans or transaction authority.

Guest preview is limited to five questions per signed browser session per UTC day, with an additional shared service safety cap. Clearing a session does not remove the shared cap. Questions are sent to the configured model provider; do not include passwords, wallet keys, API credentials or sensitive personal details.

## Connect for account tools

Wallet-authenticated chat can prepare bounded purchase proposals, inspect your account balance, explain gas information and help with Profit First scenarios. Purchases require a separate explicit confirmation. Contract actions require wallet signatures. A message alone never purchases, transfers or stakes.

The current shop delivers simulated goods only. Live AppRoute procurement, mainnet and live Earn are not enabled.

## Know which response you received

A model-backed response identifies its configured provider. A rules-based fallback is labelled separately. Provider availability is not a promise that every request will succeed: upstream quotas, timeouts and invalid responses may trigger fallback.

AI explanations are untrusted guidance. Verify important details in the interface and relevant guide. The model is given verified product facts, but this is not a guarantee of accuracy or financial, tax or legal advice.

Budget saving is a server request, not a wallet payment or contract signature. Shop limits do not apply to Gateway, external wallet transfers or Profit First allocations. See [spending limits](/docs/account/budget).

## Inspect execution evidence

The assistant's prose is not a receipt. Inspect **Shop → Purchases** and **Account → Activity** for verified test-order records. Reconcile an uncertain original operation rather than creating a replacement purchase. Never paste private keys into chat to enable signing.
