## Safe Operation Invariants

* **Blind Execution Defense**: AI agents interact exclusively through verified API quotes and atomic contracts. Language models never handle plain-text license codes or unencrypted customer secrets.
* **Deterministic Policy Gates**: Transactions failing Gross Margin Floor ($\ge 15\%$), single-transaction approval caps, or velocity limits are rejected before touching the blockchain.
* **Public Explorer Verification**: All Mainnet transactions are publicly auditable on [ArcScan](https://arcscan.app).
