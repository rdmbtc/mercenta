---
title: "Mainnet readiness"
description: "Testnet success does not equal production certification."
---

Mainnet is disabled. Before handling real funds or goods, complete merchant authorization, verified pricing/FX, supply contract integration, deterministic approvals, evidence-backed treasury reconciliation, signed webhook verification, refund/withdrawal execution, delivery-code encryption and one-time reveal, backups, recovery, security review, load tests and compliance obligations.

Testnet balances must never migrate as monetary credit to Mainnet. Real fiat cannot be exchanged for testnet credits. A public beta requires accurate availability labels, terms, support routes and an independently verified settlement path.
