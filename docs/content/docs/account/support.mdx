Start with the [quickstart](/docs/quickstart), [funding guide](/docs/account/funds) and [troubleshooting](/docs/guides/troubleshooting).

Manager, support email and RU/EN news channels are not configured yet. The console marks them unavailable rather than advertising invented contacts. Configure verified contact routes before public launch.

Never share seed phrases, private keys, API secrets or one-time delivery codes. A support case may include your public transaction hash, account/order reference, timestamp and error code.
