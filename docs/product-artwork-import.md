# Product artwork import

Retrieved 23 unique public images referenced by 24 cards in the user-provided saved catalogue page. No sign-in, supplier invoice, order or charge was used. The directory does not offer a public listing; this is not a claim to have enumerated the entire server image library.

Published 20 locally hosted platform artwork files. They match 395 of 1298 listings in the current Mercenta catalogue by explicit platform/brand name, not cross-provider product IDs. Unknown listings retain visibly illustrative covers. Source SKU prices, availability, order policy and test checkout are unchanged.

Images are resized, re-encoded to WebP and stripped of source metadata. Files are decoded and validated instead of trusting extensions or HTTP MIME headers. Aspect-fit preserves complete logos and avoids misleading crops. Remote product imagery, when actually supplied, still has priority; failed images fall back safely.

Platform artwork is visibly labeled; it does not claim a particular denomination, account top-up, stock or official affiliation. The football image whose HTML label said FC26 visually showed FC25: it was not mapped to FC26. Both football-edition covers and the supplier demo/API image are excluded from customer artwork. Confirm commercial artwork rights before mainnet rollout.

Both the public Catalogue and workspace Shop use the same component and registry. The downloaded archive retains all 23 unique originals and optimized versions for the user, outside public deployment; the saved HTML and credentials are not published.
