# Mercenta landing

Early-access landing for mercenta.xyz. Next.js 15 App Router, TypeScript, Tailwind CSS v4, Framer Motion and shadcn/ui. No checkout, wallet or supplier execution is wired into this landing; the operator is an illustrative interactive preview.

```bash
npm install
npm run dev
```

Open http://localhost:3000. Use `npm run build` for a production check. The landing CTA links to [@mercentaxyz](https://x.com/mercentaxyz); it does not register users.
